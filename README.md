# How do I approach designing software?

When I design software, I like to start by understanding the goal of the project and then breaking it into smaller pieces. For my 3D scene, I focused on planning the layout, object placement, lighting, and textures before making major changes. This project helped me develop stronger design skills by thinking about both functionality and visual presentation. I followed a process of planning, building, testing, and refining throughout the project. One of the biggest lessons I learned was that good design is often the result of continuous improvements rather than getting everything right on the first try. This is a process I can apply to future software and UX/UI projects.

# How do I approach developing programs?

I approached development by working on one feature at a time and testing frequently. While creating my 3D scene, I learned new strategies involving transformations, textures, materials, lighting, and scene organization. Breaking the project into smaller tasks made it easier to focus on individual challenges while continuing to make progress. Iteration played a major role throughout the project. I made frequent adjustments to object placement, lighting, and scene details to improve the overall result. As I progressed through the milestones, my development process became more organized, and I gained confidence in troubleshooting issues and refining my work until the project was complete.
